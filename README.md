Dependencies:
yt-dlp
(I use mac so: brew install yt-dlp or pip -m install yt-dlp)

python library "requests"
(pip -m install requests)

run it and add the public playlist + a folder and bam done. Resulting format is .mp3 and attempts to get the best quality (size around 4.5MB to 12MB depending on the length) 

Note: 
(Kinda obvious but still) if your file size is in KBs or is larger than ~16MB it probably got the wrong one...
ALSO! Max is 100 songs. Any larger and it'll get the first 100. As an alternative use https://www.chosic.com/spotify-playlist-exporter/ or smn idk (search playlist to .txt).
